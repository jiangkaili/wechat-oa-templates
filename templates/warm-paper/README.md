# Warm Paper Template

`warm-paper` 是一款暖米色背景的衬线书卷风微信图文模板，灵感来自纸质期刊与古籍书页，温润、克制、富有书卷气。

## 描述

暖米画布搭配深棕色衬线文字与暖灰标签，营造书刊阅读质感。图片配以暖色细边框与柔和圆角，适合人文、学术、长文阅读类内容。

## 设计特点

- **暖米画布**：`#FAF9F5` 主背景，`#3D3530` 深棕正文，`#8B7E6E` 暖灰辅助标签，模拟纸张质感。
- **衬线字体**：统一使用 `Georgia, serif` 衬线字体，呈现书刊阅读的正式感与古典韵味。
- **暖色细边框**：图片配以 `#D4C9B8` 暖色细边框与 `border-radius:4px` 柔和圆角，呼应书页装帧。
- **宽行距**：正文 `line-height:1.9`，宽松行距降低长文阅读疲劳，强化书卷阅读节奏。
- **金融涨跌着色**：内置 `colorUpDown` 函数，`+X%` 自动标绿、`-X%` 自动标红，兼容财经数据呈现。

## 色板

| 用途 | 颜色 |
| --- | --- |
| 主背景 | `#FAF9F5` |
| 标题文字 | `#3D3530` |
| 正文文字 | `#5C5048` |
| 辅助标签 | `#8B7E6E` |
| 分隔线/边框 | `#D4C9B8` |
| 涨色（+） | `#22C55E` |
| 跌色（−） | `#EF4444` |

## 用法

在文章 JSON 中设置 `"style": "warm-paper"`，由 `publish_generic.py` 自动加载
`templates/warm-paper/composer.py` 的 `compose_html(article_data, image_urls)` 渲染正文 HTML。

可参考同目录 `example.json` 查看示例数据结构（含金融涨跌字段与日期）。
