# Dark Mode Template

`dark-mode` 是一款深色背景的现代科技风微信图文模板，灵感来自 Apple 暗色模式与科技媒体夜间界面，克制、清晰、信息密度高。

## 描述

深色画布配合白色文字与灰色辅助标签，强调内容本身而非装饰。无卡片、无阴影，仅以细分隔线划分层次，适合科技、财经、AI 资讯等需要在夜间场景下长时间阅读的内容。

## 设计特点

- **深色画布**：`#1D1D1F` 主背景，`#F5F5F7` 白色标题文字，`#86868B` 灰色辅助标签，长时间阅读不刺眼。
- **细分隔线**：仅以 `#383838` 的细横线区分章节，无卡片、无阴影，保持界面平整克制。
- **大留白**：统一 `30px` 横向内边距与充足的纵向间距，呼吸感强，契合现代科技美学。
- **金融涨跌着色**：内置 `colorUpDown` 函数，`+X%` 自动标绿、`-X%` 自动标红，适合财经资讯。
- **图片圆角**：内容图统一 `border-radius:8px`，与整体圆角风格一致。

## 色板

| 用途 | 颜色 |
| --- | --- |
| 主背景 | `#1D1D1F` |
| 标题文字 | `#F5F5F7` |
| 正文文字 | `#D1D1D6` |
| 辅助标签 | `#86868B` |
| 分隔线 | `#383838` |
| 涨色（+） | `#22C55E` |
| 跌色（−） | `#EF4444` |

## 用法

在文章 JSON 中设置 `"style": "dark-mode"`，由 `publish_generic.py` 自动加载
`templates/dark-mode/composer.py` 的 `compose_html(article_data, image_urls)` 渲染正文 HTML。

可参考同目录 `example.json` 查看示例数据结构（含金融涨跌字段与日期）。
