# Apple Minimalist

纯白底 + 黑灰双色，Apple Newsroom 风格。当前默认模板。

## 设计特点

- 纯白背景 #FFFFFF，无卡片无阴影
- 黑色标题 #1D1D1F + 灰色正文 #555555 + 浅灰标签 #86868B
- 章节标题加粗 18px，带浅灰下划线 #E5E5E5
- 正文 15px，行高 1.8，大间距
- 图片圆角 8px，居中
- 无序号、无 footer
- 美股涨跌自动标色（正绿 #22C55E 负红 #EF4444）

## 色板
